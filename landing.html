FAQ

Things buyers ask first.

If your question isn't here, ping @TomSmart_ai.

How do I pay if I don't have USDC on Base?

Bridge ETH from Ethereum mainnet via Superbridge (5-10 min), then swap to USDC on Uniswap Base. The README has a step-by-step. Coinbase users can also withdraw USDC directly to Base from the exchange UI for zero fees.

What stack does the starter target?

Python 3.12 + FastAPI on the server side. The middleware is pure Python with pydantic models — no Node.js required. Postgres schema ships as Drizzle migrations for buyers who prefer TS tooling alongside.

Is the core middleware really MIT?

Yes. The middleware module is MIT-licensed and the source lives on GitHub. The paid tiers add example endpoints, Solana auth, deploy playbooks, MCP server templates — production glue, not the protocol primitive.

Can I self-host the facilitator instead of CDP?

Yes. Leave CDP_API_KEY unset and point FACILITATOR_URL at your own /verify and /settle endpoints. The middleware speaks the standard x402 v0.5 envelope — any compliant facilitator works.

What's in the Pro Bundle's MCP servers?

Three Model Context Protocol server templates: a mapper-style catalog server, a signal-feed reader, an agent-coordination scaffold. Each ships with manifest, tools, and a working sample. Drop into Claude Desktop or Cursor in minutes.

What if the kit doesn't work for me?

Refund window is 48 hours from purchase — DM @TomSmart_ai with the tx hash and reason. Refunds settle in USDC back to the paying wallet.

Why no Stripe, no PayPal, no LemonSqueezy?

This kit is x402-native by design. Crypto buyers are the audience, and shipping a crypto product behind a fiat gateway felt like a contradiction. Fiat rails may come later; today the rail is USDC on Base.
